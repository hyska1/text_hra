Sjezd na horském kole (Textová hra)

Krátká interaktivní textová hra v Pythonu, ve které si nejprve poskládáš vlastní kolo a následně se vydáš na sjezdovou trať. Tvá volba ráfků a brzd přímo ovlivňuje rychlost a riziko pádu na jednotlivých překážkách.

## 🚀 Jak hru spustit
1. Ujisti se, že máš nainstalovaný Python 3.
2. Stáhni si soubor se hrou ("ctvrtletni_projekt_2.py")
